# Python Data Analytics & Text Mining

**Course:** AA640 - Data Analytics and Text Mining  
**Institution:** Bryant University  
**Tools:** Python, Google Colab, Pandas, Matplotlib, Seaborn, NLTK, scikit-learn, Gensim, pyLDAvis, WorldCloud

## Overview

This repository documents nine hands-on notebooks from AA640, a graduate-level Data Analytics and Texting mining course. The notebooks cover a progression of topics, from programming fundamentals and data preparation to visualization, text analysis, and natural language processing (NLP) techniques. 

## Notebook Progression

| # | Notebook | Topics Covered |
|---|---|---|
| 01 | [Python Basics & Data Types](01_python_basics_data_types.ipynb) | Variables, data types, lists, tuples, dictionaries, and strings |
| 02 | [Logic & Control Flow](02_logic_and_control_flow.ipynb) | Conditional statements, operators, and loops |
| 03 | [Functions, Files & Pandas](03_functions_files_pandas.ipynb) | Functions, file handling, Series, and DataFrames |
| 04 | [Aggregation & Data Cleaning](04_aggregation_data_cleaning.ipynb) | GroupBy, aggregation, missing values, and duplicates |
| 05 | [Data Visualization](05_data_visualization.ipynb) | Charts and visualizations using Matplotlib and Seaborn |
| 06 | [Text as Data](06_text_as_data.ipynb) | Regular expressions, tokenization, and text preprocessing |
| 07 | [Text Vectorization](07_text_vectorization.ipynb) | Bag-of-words, TF-IDF, and n-gram analysis of Romeo and Juliet and 2016 U.S. presidential primary debates|
| 08 | [Sentiment Analysis](08_sentiment_analysis.ipynb) | Sentiment scoring and emotion analysis |
| 09 | [Topic Modeling](09_topic_modeling.ipynb) | Latent Dirichlet Allocation (LDA) and topic interpretation of 1,000 historical U.S. newspaper articles (1958) |

## Skills Demonstrated

**Python Programming**
- Data structures, functions, loops, and conditional logic
- File handling and data processing

**Data Analysis**
- Data manipulation and aggregation using Pandas
- Data cleaning and handling missing values
- Exploratory data analysis

**Data Visualization**
- Creating and interpreting charts with Matplotlib and Seaborn

**Natural Language Processing**
- Text preprocessing and regular expressions
- Text vectorization using TF-IDF
- Sentiment analysis and topic modeling

## How to Run

1. Open any notebook from the table above.
2. Select Open in Colab or upload the notebook to Google Colab.
3. Install any required libraries and upload supporting datasets when prompted.
4. Run the notebook cells in sequence.
